## 结论与限制

- 用户手推后，真实分割、视觉里程计、几何建图与语义累积均曾正常输出。后期RGB-D视觉里程计持续报匹配不足，程序在持续失跟踪15秒后自动保存退出。分割仍正常，几何地图随后停止增长。
- 跟踪丢失导致14个语义点云缺少采集时刻TF而未累积；RTAB-Map记录14条“无有效里程计”错误。相机、雷达、分割、投影、录制和视频进程未记录程序错误，均正常退出。该结果不能称为完整路线建图成功。
- 全部计算在Jetson本机、隔离ROS域77进行；丢失时RGB-D仍持续录制，因此当前证据不支持“离VMware电脑远”是主要原因。
- 直角路线本身合理。具体失跟踪诱因尚未定位，不能简单归咎于推车。录制时CPU确有满载采样，但尚未证明其与失跟踪的因果关系。
- 使用相机自带TF及相机视觉里程计；未伪造底盘安装TF。雷达只采集，没有融合雷达、轮速或IMU；地图为相机参考系下的局部预览，不能直接作为底盘导航地图。
- COCO预测包括误识别，未作精度验收；关键帧和视频中Mask均来自原版YOLO。没有部署MobileNet或进行训练。
- 首轮`runs/handpush-20261023-155002/`另保存290帧分割、48个图位姿和40,760个语义体素，后期同样失跟踪；不能将两轮无标定位姿的地图直接拼接。
