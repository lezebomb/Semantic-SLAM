## 5. 接口如何调用

以下命令只读取消息，车辆恢复供电后按当时状态使用。本轮实际接收由被动订阅脚本完成，不把下面每一条CLI写成已经逐条执行。

```bash
source /etc/jetson-ros/ros2-env.sh
# 本轮工作域为ROS2 Domain 0
ros2 topic info /scan --verbose
ros2 topic echo /scan sensor_msgs/msg/LaserScan --once --field header
ros2 topic echo /camera/camera/color/image_raw sensor_msgs/msg/Image --once --field header
ros2 topic echo /camera/camera/aligned_depth_to_color/image_raw sensor_msgs/msg/Image --once --field header
ros2 topic echo /camera/camera/color/camera_info sensor_msgs/msg/CameraInfo --once
ros2 topic echo /odom nav_msgs/msg/Odometry --once
ros2 topic echo /encoder std_msgs/msg/Float32MultiArray --once
```

无数据时单次echo会等待，可用Ctrl+C退出。底盘反馈经动态桥接时，显式指定消息类型可帮助建立ROS1到ROS2的订阅转发；这仍不保证串口已有有效数据。压缩图像和 `/map` 本轮只确认了发布端，尚未验证消息接收。`/cmd_vel`、`/chassis_param`、`/charge_enable` 和地图保存服务未执行调用。
