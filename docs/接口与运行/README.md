- **已接收**：实际订阅到消息；必须同时看日期、窗口、ROS 域和单位说明。
- **有发布端、窗口内 0 条**：图中看到端点，短时间内没有收到消息；不能据此判断设备故障或状态失败。

- **未观察到发布端**：本次在已查 Domain 中未发现；不是对所有机器和所有 Domain 的全面判断。
