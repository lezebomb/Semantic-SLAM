- [恢复脚本](车上原始结果/恢复原始录包.sh)：参数all、first、formal。恢复全量需约11.56GB额外空间。

```bash
bash "RTAB-Map + YOLO/实车测试结果_20261105/车上原始结果/恢复原始录包.sh" formal
```

原始归档保留了当时的传感器、旧语义输出、融合位姿、动态TF和控制消息。后续只通过主工程`run.sh --replay`的白名单读取RGB、对齐深度、CameraInfo和相机内部静态TF，重新计算视觉里程计与RTAB-Map地图；旧轮速、旧动态TF、融合位姿、语义结果及控制消息不进入当前回放。

本机恢复版的9项检查、CPU软件检查和隔离短回放证据见主工程`tests/启动验证记录.json`，不代表新实车测试已经通过。历史归档中的轮速与雷达消息仅作为既有输入保留，当前基线不会读取。
