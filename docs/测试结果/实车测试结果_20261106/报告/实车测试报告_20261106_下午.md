# 语义SLAM实车测试报告（2026-11-06，核查修订）

## 1. 结论与范围

11月6日的记录证明本组 RTAB-Map、YOLOv8n-seg、语义投影、地图累积及录制链路曾实际运行，但没有证明形成了可靠的完整场地地图。轮速估计与控制指令存在明显不一致，是优先排查的定位输入；CPU高负载、TF时序、输入中断和启动判断问题也分别出现在记录中，不能用一个原因概括全部失败。

本报告核查全部17个运行目录，重点分析13:55至15:23启动的8次轮速输入测试。后9次是移除轮速、尝试激光ICP及启动配置的调试，不作为已通过的RGB-D手推基线。15:23“已绕场地一圈”来自现场操作者记录；未取得实测路径长度、参考轨迹或分割标注。

当前交付代码恢复为RGB-D手推路线：`rtabmap_odom/rgbd_odometry`提供视觉里程计，`rtabmap_slam/rtabmap`构建几何图，原版YOLOv8n-seg提供实例掩膜和语义点云。新基线不订阅轮速或雷达，也不启动手柄/底盘程序；恢复代码的本机检查与历史实车结果分开记录。

## 4. 轮速输入异常的直接证据

以15:23运行为例，将每条轮速估计与此前最近的`/cmd_vel`匹配，最大接收时间间隔0.25 s。选取指令线速度绝对值不小于0.05 m/s、角速度绝对值不大于0.02 rad/s的样本，得到：

| 统计项 | 结果 |
|---|---|
| 匹配到的直行指令样本 | 3507 |
| 轮速估计线速度绝对值中位数 | 0.0080 m/s |
| 轮速估计角速度绝对值中位数 | 0.9699 rad/s |
| 轮速估计角速度绝对值大于0.2 rad/s的比例 | 98.20% |

直行请求对应了接近零的线速度和较大的角速度估计。13:55、14:15和14:24也出现同类模式，因此应先核对左右轮极性、通道顺序、符号和单位，再检查轮径、轮距及缩放参数。指令不是运动真值，上述匹配未估计执行延迟，不能据此计算定位RMSE、标定系数或“少报三倍”。
